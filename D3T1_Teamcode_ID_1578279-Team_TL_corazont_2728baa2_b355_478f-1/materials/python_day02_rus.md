## Как устроена программа дня

Программа состоит из двух файлов в папке `src/`:

- `main.py` — готов. Принимает путь к банку и флаг, вызывает функции из `bank.py`, печатает результат.
- `bank.py` — твой. В нём функции, которые читают банк и считают. Они ничего не печатают, а **возвращают** результат.

Твоя работа — написать тела функций в `bank.py`. Названия функций и их описания уже есть: описание — это текст в тройных кавычках сразу под строкой `def`. Прочитай его, прежде чем писать тело.

## Чтение файла

```python
with open(path, encoding="utf-8") as source:
    text = source.read()
```

- `open(path, encoding="utf-8")` открывает файл по пути `path`. Кодировку указывают всегда: в банке есть русские буквы.
- `with ... as source:` — файл открыт, пока идут строки с отступом, потом закрывается сам.
- `source.read()` читает весь файл в одну строку `text`.

Разделить текст на строки файла:

```python
lines = text.split("\n")
```

В конце файла обычно стоит перевод строки, поэтому последним элементом окажется пустая строка `""`. Убрать её:

```python
if lines and lines[-1] == "":
    lines.pop()
```

Если файла нет, `open` останавливает программу ошибкой `FileNotFoundError`. В `bank.py` её перехватывать не нужно: это делает `main.py`.

## Списки

Список хранит несколько значений по порядку.

| Что пишем | Что получаем |
| --- | --- |
| `items = []` | Пустой список |
| `items = [3, 1, 2]` | Список из трёх чисел |
| `items.append(x)` | Добавить `x` в конец |
| `len(items)` | Сколько элементов: `len([3, 1, 2])` → `3` |
| `items[0]` | Первый элемент: `[3, 1, 2][0]` → `3` |
| `items[1]` | Второй элемент: нумерация начинается с нуля |
| `items[-1]` | Последний элемент |
| `items[1:]` | Новый список без первого элемента: `[3, 1, 2][1:]` → `[1, 2]` |
| `items.pop()` | Убрать последний элемент |
| `x in items` | Есть ли `x` в списке: `2 in [3, 1, 2]` → `True` |
| `sum(items)` | Сумма чисел: `sum([3, 1, 2])` → `6` |
| `sorted(items)` | Новый список по порядку |

Пустой список в условии считается ложью: `if not items:` — «список пуст».

Обращение к элементу, которого нет, останавливает программу: `[3, 1, 2][5]` → `IndexError`.

## Цикл for

`for` выполняет одни и те же строки для каждого элемента списка по очереди.

```python
total = 0
for n in [1, 2, 3]:
    total = total + n
print(total)
```

Здесь `n` по очереди равно `1`, `2`, `3`, и после цикла `total` равно `6`. Строки внутри цикла сдвинуты на четыре пробела, как у `if`.

Нужен номер по порядку — заведи счётчик:

```python
number = 1
for word in ["лес", "бор"]:
    print(number, word)
    number = number + 1
```

Напечатает `1 лес` и `2 бор`.

Пропустить элемент и перейти к следующему — `continue`:

```python
for word in ["лес", "", "бор"]:
    if word == "":
        continue
    print(word)
```

Напечатает `лес` и `бор`: пустая строка пропущена.

## Строки: разрезать, заменить, склеить

| Что пишем | Что получаем |
| --- | --- |
| `"a;b;c".split(";")` | Список `["a", "b", "c"]` |
| `"a;;c".split(";")` | `["a", "", "c"]` — пустое поле тоже элемент |
| `"a b  c".split()` | `["a", "b", "c"]` — без аргумента режет по пробелам, лишние пробелы не дают пустых элементов |
| `"ab".split()` | `["ab"]` — пробелов нет, получается один элемент |
| `"да\|нет".split("\|")` | `["да", "нет"]` |
| `text.replace("а", "о")` | Новая строка, где каждое `а` заменено на `о` |
| `"-".join(["a", "b"])` | `"a-b"` — склеить список в строку |
| `"5" + "5"` | `"55"` — строки склеиваются, а не складываются |
| `"ab" * 2` | `"abab"` — строка повторяется |
| `str(3) + ") лес"` | `"3) лес"` — число сначала превращают в строку |

**Перенос строки в тексте вопроса.** В файле банка перенос строки записан двумя символами: обратной косой чертой и буквой `n`. В Python настоящий перенос строки пишется `"\n"`, а два символа «обратная косая + n» — `"\\n"` (обратная косая удвоена). Поэтому заменить записанный перенос настоящим можно так:

```python
text = text.replace("\\n", "\n")
```

После этого `text.split("\n")` разрежет текст вопроса на строки экрана.

## Числа и арифметика

| Что пишем | Что получаем |
| --- | --- |
| `int("42")` | Число `42` |
| `int("08")` | Число `8`: ведущий ноль не мешает |
| `int(" 7 ")` | Число `7`: пробелы по краям `int` пропускает |
| `int("1.5")`, `int("три")`, `int("")`, `int("  ")` | Ошибка `ValueError` |
| `7 + 2`, `7 - 2`, `7 * 2` | `9`, `5`, `14` |
| `7 / 2` | `3.5` — деление с дробной частью |
| `7 // 2` | `3` — целая часть от деления |
| `7 % 3` | `1` — остаток от деления |
| `10 // 0`, `10 / 0` | Ошибка `ZeroDivisionError`: на ноль делить нельзя |

`"3" * 2` — это строка `"33"`, а `3 * 2` — число `6`. Если значение пришло из файла, это строка, пока ты не превратил её в число через `int`.

Сравнения и логика — как в первом дне: `==`, `!=`, `<`, `>`; `and` — верны оба условия, `or` — верно хотя бы одно, `not` — условие неверно.

## Словари

Словарь хранит пары «ключ — значение». По ключу быстро находится значение.

```python
question = {"id": 23, "level": 2, "text": "Что напечатает код?"}
print(question["level"])
```

Напечатает `2`.

| Что пишем | Что делает |
| --- | --- |
| `d = {}` | Пустой словарь |
| `d = {"a": 1, "b": 2}` | Словарь из двух пар |
| `d["a"]` | Значение по ключу `"a"`; если ключа нет — ошибка `KeyError` |
| `d["c"] = 3` | Положить значение по ключу (новое или заменить старое) |
| `d.get("c", 0)` | Значение по ключу или `0`, если ключа нет — без ошибки |
| `"a" in d` | Есть ли такой ключ |
| `len(d)` | Сколько пар |
| `for key in d:` | Перебрать ключи |

Ключом может быть строка или число: `{1: 10, 2: 9}` — словарь, где ключи — числа `1` и `2`.

Значением может быть что угодно, даже другой словарь:

```python
table = {"лес": {1: 0, 2: 0}}
table["лес"][2] = table["лес"][2] + 1
```

После этого `table["лес"][2]` равно `1`.

## Подсчёт через словарь

Посчитать, сколько раз встретилось каждое слово:

```python
counts = {}
for word in ["да", "нет", "да"]:
    counts[word] = counts.get(word, 0) + 1
```

После цикла `counts` равно `{"да": 2, "нет": 1}`. `get(word, 0)` даёт текущее число или `0`, если слово встретилось впервые.

Если нужно, чтобы в словаре были все ключи — даже те, что не встретились ни разу, — сначала положи их с нулём:

```python
counts = {"да": 0, "нет": 0, "может": 0}
for word in ["да", "нет", "да"]:
    counts[word] = counts[word] + 1
```

Теперь `counts` равно `{"да": 2, "нет": 1, "может": 0}`.

## Функции

Функция — именованный кусок программы. Её объявляют через `def` и вызывают по имени со скобками.

```python
def double(number):
    """Удвоить число."""
    return number * 2


result = double(6)
print(result)
```

- В скобках после имени — **параметры**: значения, которые функция получает при вызове.
- `return` — что функция **возвращает**. После `return` функция заканчивается.
- Если функция дошла до конца без `return`, она возвращает `None` — «ничего».
- Объявление функции её не запускает. Функция работает, только когда её вызвали.

Вернуть можно сразу два значения — через запятую. Получить их — тоже через запятую:

```python
def split_name(full):
    parts = full.split()
    return parts[0], parts[1]


first, last = split_name("Анна Иванова")
```

**Вернуть — не то же самое, что напечатать.** `print` показывает значение на экране, но функция, в которой только `print`, возвращает `None`. Код, который вызвал её, ничего не получит.

Искать в списке и вернуть найденное:

```python
def find_word(words, letter):
    for word in words:
        if word[0] == letter:
            return word
    return None
```

Как только нужное слово найдено, `return` сразу заканчивает функцию. `return None` после цикла сработает, только если ничего не нашлось.

## Модуль и импорт

Модуль — это просто файл `.py`. Если рядом лежат `main.py` и `bank.py`, в `main.py` можно подключить второй:

```python
import bank

questions, skipped = bank.load_bank("datasets/bank.csv")
```

Функцию из модуля вызывают так: `имя_модуля.имя_функции(...)`. Файл `__init__.py` для этого не нужен.

**В модуле нет `print`.** Модуль считает и возвращает, печатает точка входа. Модуль, который печатает сам, нельзя использовать там, где нужен другой вывод: например, в тестах или в экзамене завтра.

Если `bank.py` не загружается, Python пишет `ModuleNotFoundError: No module named 'bank'`. Проверь, что файл называется именно `bank.py`, лежит в `src/`, а запуск идёт из корня репозитория.

## Исключения: try и except

Некоторые операции не возвращают «ошибку», а останавливают программу. `int("три")` не даёт ничего — он останавливает всё с `ValueError`.

Перехватить такую остановку:

```python
try:
    number = int(text)
except ValueError:
    number = 0
```

`try` — попробовать; `except ValueError` — что делать, если случилась именно эта ошибка. Если ошибки не было, строки после `except` не выполняются.

**Где ставить try.** Оборачивай одну операцию, от которой ждёшь конкретную ошибку, — а не всю программу. Если файл читается строка за строкой, `try` ставят внутри цикла вокруг разбора одной строки: тогда испорченная строка пропускается, а цикл идёт дальше.

```python
good = []
for text in ["1", "два", "3"]:
    try:
        good.append(int(text))
    except ValueError:
        continue
```

После цикла `good` равно `[1, 3]`.

**Всегда называй ошибку.** Голое `except:` без имени ловит вообще всё, включая твои опечатки, и прячет их.

Часто можно обойтись без `try`: сначала проверить, потом превращать.

```python
if text in ["1", "2", "3"]:
    number = int(text)
```

| Ошибка | Когда возникает |
| --- | --- |
| `ValueError` | Значение не того вида: `int("три")`, `int("1.5")` |
| `ZeroDivisionError` | Деление на ноль |
| `FileNotFoundError` | Нет файла по такому пути |
| `KeyError` | В словаре нет такого ключа |
| `IndexError` | В списке нет элемента с таким номером |

## Временная печать для отладки

> В Д3–Д4 `bank.py` выдан готовым и не меняется, а `main.py` нет. Печатай так же, но в своём файле — `answers.py` или `ladder.py`, — и запускай тесты или экзамен.

Если непонятно, что лежит в переменной, её можно временно напечатать прямо в `bank.py` — внутри функции, которую пишешь:

```python
    for line in lines[1:]:
        fields = line.split(";")
        print("ОТЛАДКА:", fields)
```

Запусти программу как обычно, например `python3 src/main.py datasets/bank.csv`. Строки `ОТЛАДКА: …` появятся на экране перед обычным ответом. Слово `ОТЛАДКА` помогает не перепутать их с настоящим выводом.

Чтобы увидеть и невидимое — пробелы, пустые строки, `\n`, — печатай через `repr`: `print("ОТЛАДКА:", repr(text))`.

Когда разобрался, удали эти строки. Если забудешь, линтер напомнит: замечание `L020 модуль не должен печатать`. Перед коммитом отладочной печати в `bank.py` быть не должно.
