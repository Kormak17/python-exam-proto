## Как устроен файл

- Обычный текстовый файл в кодировке UTF-8. Открывается в `nano`, читается `cat`.
- Одна строка — один вопрос. Пустых строк нет.
- Первая строка — заголовок с названиями полей. Это не вопрос.
- Поля в строке разделены символом `;` (точка с запятой). Полей всегда ровно семь.

Заголовок:

```
id;тема;уровень;тип;вопрос;варианты;ответ
```

Пример строки-вопроса:

```
1;строки;1;один;Какая функция читает строку, которую ввёл человек?;print|input|int|len;2
```

Так как поля разделены `;`, каждое поле внутри строки стоит между двумя `;`. Первое поле стоит в начале строки, последнее — в конце.

## Поля

| № | Поле | Что в нём | Пример |
| --- | --- | --- | --- |
| 1 | `id` | Номер вопроса, целое число больше нуля, без нулей в начале: `7`, а не `07`. Номера не повторяются. У выданных вопросов — от 1 до 40, у вопросов команды — от 101 | `1` |
| 2 | `тема` | Одна из четырёх тем, список ниже | `строки` |
| 3 | `уровень` | Сложность от `1` до `5` | `1` |
| 4 | `тип` | `один`, `несколько` или `короткий` | `один` |
| 5 | `вопрос` | Текст вопроса | `Какая функция читает строку, которую ввёл человек?` |
| 6 | `варианты` | Варианты ответа через `\|`. У типа `короткий` поле пустое | `print\|input\|int\|len` |
| 7 | `ответ` | Правильный ответ, форма зависит от типа | `2` |

Если в вопросе есть код из нескольких строк, переход на новую строку записывается двумя символами `\n`. Экзамен при показе вопроса заменит их настоящим переносом строки.

```
23;списки;2;короткий;Что напечатает код?\nitems = [3, 1, 2]\nprint(items[0]);;3
```

Этот вопрос человек увидит так:

```
Что напечатает код?
items = [3, 1, 2]
print(items[0])
```

## Типы вопросов

| Тип | Что делает человек | Поле `варианты` | Поле `ответ` |
| --- | --- | --- | --- |
| `один` | Выбирает один вариант и вводит его номер | От 2 до 5 вариантов через `\|` | Номер правильного варианта: `2` |
| `несколько` | Выбирает все правильные варианты и вводит номера через запятую | От 2 до 5 вариантов через `\|` | Номера всех правильных вариантов через запятую без пробелов и без нулей в начале: `1,3` |
| `короткий` | Сам пишет ответ | Пустое | Все принимаемые формы ответа через `\|`: `strip\|strip()` |

Варианты нумеруются по порядку, начиная с `1`. У типа `несколько` правильных вариантов не меньше двух, а верным считается только полный набор. Ответ типа `короткий` сравнивается без учёта пробелов по краям и больших и маленьких букв, поэтому `Print` и `print` — один и тот же ответ.

Ответ на вопрос должен быть однозначным по правилам своего типа: в `один` верен ровно один вариант, в `несколько` — ровно один набор, в `короткий` перечислены все формы, которые считаются верными.

## Почему в тексте нет точки с запятой

Строка банка делится на поля по каждому символу `;`. Если `;` окажется внутри текста вопроса, строка разделится на восемь частей вместо семи, и программа не поймёт, где какое поле.

Поэтому **в тексте вопроса, в вариантах и в ответах символ `;` запрещён**. По той же причине `|` используется только как разделитель вариантов и форм ответа.

В коде Python точка с запятой почти никогда не нужна. Она позволяет записать две команды в одну строку:

```python
x = 1; print(x)
```

Без неё те же команды пишут на двух строках — и работают они точно так же:

```python
x = 1
print(x)
```

В банке перенос строки записывается как `\n`, так что код без `;` остаётся одной строкой файла.

## Темы и уровни

| Тема | О чём вопросы |
| --- | --- |
| `строки` | Ввод, вывод, строки и их методы |
| `числа` | Числа, преобразование строки в число, арифметика, условия |
| `списки` | Списки, словари, циклы |
| `ошибки` | Сообщения об ошибках, исключения, код завершения |

| Уровень | Что требуется от отвечающего |
| --- | --- |
| 1 | Узнать название или назначение: «какая функция делает…» |
| 2 | Применить одно правило к конкретному значению |
| 3 | Выбрать правильное сочетание действий из нескольких |
| 4 | Проследить несколько шагов выполнения кода |
| 5 | Найти пример, на котором код или проверка ошибается |

Длина текста уровень не определяет: короткий вопрос может быть пятого уровня, а длинный — первого.

Ответ на любой вопрос банка можно найти в справочниках первого и второго дня.

## Пустые клетки банка

Если сложить все сочетания темы и уровня, получится таблица из 20 клеток: 4 темы × 5 уровней. В выданном банке четыре клетки пустые — вопросов с таким сочетанием нет:

| Тема | Уровень |
| --- | --- |
| `строки` | 5 |
| `числа` | 3 |
| `списки` | 1 |
| `ошибки` | 4 |

Вопросы команды закрывают эти клетки. Проверить, остались ли пустые клетки в двух банках вместе:

```
python3 src/partner/matrix.py datasets/team.csv datasets/bank.csv
```

## Какая строка считается испорченной

Строка банка испорчена, если выполняется хотя бы одно из трёх условий:

1. строка пустая или состоит из одних пробелов;
2. полей не ровно семь — например, в тексте оказалась лишняя `;`;
3. уровень — не число от `1` до `5`: например, `6`, `0` или `два`.

Испорченная строка не попадает в список вопросов, программа считает её пропущенной и идёт дальше. Заголовок — первая строка файла — не вопрос и не испорченная строка: его просто пропускают.

Выданная проверка банка строже: она ловит и другие ошибки формата. Проверяйте ею вопросы команды после каждой правки — вместе с выданным банком, чтобы номера не повторялись и между файлами:

```
python3 src/partner/check_bank.py datasets/team.csv datasets/bank.csv
```

## Как проверить банк

```bash
python3 src/partner/check_bank.py datasets/bank.csv
```

Проверка читает банк и сообщает номер строки файла и что с ней не так. Номер строки считается с начала файла, заголовок — строка 1. Если всё в порядке, проверка пишет `Банк в порядке` и завершается с кодом `0`, иначе — с кодом `1`.

Проверка смотрит только на формат: число полей, темы, уровни, типы, номера ответов. Правильный ли ответ по смыслу, она не знает: это проверяют люди.
