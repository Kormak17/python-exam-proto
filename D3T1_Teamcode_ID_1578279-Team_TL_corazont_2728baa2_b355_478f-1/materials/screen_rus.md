# Образец экрана экзамена

Здесь — точный вид того, что экзамен печатает. Строки, которые набирает человек, помечены справа `← вводит человек`: их программа не печатает.

## Полный пример

```
Как тебя зовут?
Аня                                         ← вводит человек

Вопрос 1 из 10
Какая функция читает строку, которую ввёл человек?
1) print
2) input
3) int
4) len
Введи номер варианта.
2                                           ← вводит человек
Верно.

Вопрос 2 из 10
Что напечатает код?
w = "  hi  "
print(w.strip() + "!")
Напиши ответ.
hi!                                         ← вводит человек
Верно.

Вопрос 3 из 10
Человек вводит ответ с пробелами по краям и большими буквами. Какое выражение приводит ответ answer к виду для сравнения?
1) answer.strip().lower()
2) answer.lower()
3) answer.strip()
4) answer.split()
Введи номер варианта.
2                                           ← вводит человек
Неверно.

…

Итог: уровень 2.
Почему: последний правильный ответ — на уровне 2.
```

## Правила экрана

- Экзамен начинается строкой `Как тебя зовут?`. Пустое имя записывается как `без имени`. Символ `;` в имени заменяется пробелом: он разделяет поля в `results.csv`.
- Перед каждым вопросом — пустая строка, затем `Вопрос N из 10`.
- Потом — строки вопроса и варианты: их даёт `bank.question_lines(question)`.
- Последняя строка вопроса — подсказка, как отвечать:

| Тип | Подсказка |
| --- | --- |
| `один` | `Введи номер варианта.` |
| `несколько` | `Введи номера всех верных вариантов через запятую.` |
| `короткий` | `Напиши ответ.` |

- После ответа — одна строка: `Верно.`, `Неверно.` или `Нет ответа.`
- Номер вопроса и число `10` не зависят от того, сколько вопросов в банке.

## Итог

Перед итогом — пустая строка, затем две строки.

Если верные ответы были:

```
Итог: уровень 3.
Почему: последний правильный ответ — на уровне 3.
```

Если верных ответов не было:

```
Итог: не определён.
Почему: ни одного правильного ответа.
```

С флагом `--stable` (дополнительное Задание 6) строки итога другие, например:

```
Итог: уровень 3.
Почему: уровень 3 — самый высокий, где у тебя 2 верных ответа (2 из 3). На уровне 4 верных ответов нет (0 из 2).
```

## Конец ввода и пустые ответы

| Что случилось | Что делает экзамен |
| --- | --- |
| Человек нажал Enter, ничего не написав | `Нет ответа.`, уровень не меняется, экзамен продолжается |
| Ввод закончился (Ctrl+D) на вопросе об имени | Печатает `Экзамен не начат.`, завершается с кодом `0`, в `results.csv` ничего не пишет |
| Ввод закончился на вопросе экзамена | Этот вопрос считается заданным, печатается `Нет ответа.`, затем сразу итог |
| Нет файла банка | `Файл не найден: ПУТЬ`, код `1` |

## Файл results.csv

После каждого экзамена в конец файла `results.csv` в корне репозитория дописывается одна строка:

```
имя;уровень;задано;верно
```

- `уровень` — число или `не определён`;
- `задано` — сколько вопросов было показано, включая вопрос, на котором закончился ввод;
- `верно` — сколько ответов было верными.

Пример: `Аня;2;10;6`. Файл `results.csv` не сдаётся: он уже указан в `.gitignore`.
