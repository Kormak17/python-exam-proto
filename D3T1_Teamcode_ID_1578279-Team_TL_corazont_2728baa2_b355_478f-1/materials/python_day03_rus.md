## Как части экзамена вызывают друг друга

```python
import answers
import ladder

result = answers.check_answer(question, raw)
level = ladder.next_level(level, result)
```

`exam.py` подключает модули и вызывает их функции по имени. Поэтому названия функций в заготовках менять нельзя: иначе `exam.py` не найдёт функцию и остановится с `AttributeError: module 'answers' has no attribute …`.

Пока коллега не написал свою часть, работает его заготовка: она возвращает простейший ответ, и экзамен проходит до конца.

## Чтение ответа и конец ввода

```python
import sys

line = sys.stdin.readline()
```

| Что ввёл человек | Что вернёт `readline()` |
| --- | --- |
| `hi` и Enter | `"hi\n"` |
| Только Enter | `"\n"` |
| Ctrl+D — ввод закончился | `""` |

Только конец ввода даёт совсем пустую строку `""`. Поэтому проверять конец ввода нужно **до** того, как убирать перевод строки:

```python
line = sys.stdin.readline()
if line == "":
    print("ввод закончился")
else:
    line = line.rstrip("\n")
```

`rstrip("\n")` убирает перевод строки только справа. `input()` на конце ввода останавливает программу с `EOFError` — поэтому в экзамене удобнее `readline()`.

## Цикл while и break

`while` повторяет строки, пока условие верно:

```python
count = 0
while count < 3:
    print(count)
    count = count + 1
```

Напечатает `0`, `1`, `2`.

`break` сразу выходит из цикла, даже если условие ещё верно:

```python
for word in ["лес", "стоп", "бор"]:
    if word == "стоп":
        break
    print(word)
```

Напечатает только `лес`.

## Пары значений и история ответов

Несколько значений можно хранить вместе — в круглых скобках. Такая пара называется кортежем:

```python
answer = (2, "верно")
level, result = answer
```

Список пар удобно перебирать, сразу раскладывая каждую пару на две переменные:

```python
history = [(1, "верно"), (2, "неверно"), (1, "верно")]
for level, result in history:
    if result == "верно":
        print(level)
```

Напечатает `1` и `1`.

Чтобы найти **последний** подходящий элемент, запоминай его в переменной на каждом шаге — после цикла в ней останется последний:

```python
last = None
for word in ["лес", "бор", "луг"]:
    if word.startswith("л"):
        last = word
```

После цикла `last` равно `"луг"`.

## Склеить два списка

```python
first = [1, 2]
second = [3]
both = first + second
```

`both` равно `[1, 2, 3]`: сначала элементы первого списка, потом второго.

## Ближайшее число: abs, min, max

| Что пишем | Что получаем |
| --- | --- |
| `abs(-3)` | `3` — расстояние до нуля, без знака |
| `abs(2 - 5)` | `3` — расстояние между 2 и 5 |
| `min(4, 7)` | `4` — меньшее |
| `max(4, 7)` | `7` — большее |
| `min(level + 1, 5)` | На единицу больше, но не больше 5 |

## Запись в конец файла

```python
with open("notes.txt", "a", encoding="utf-8") as target:
    target.write("новая строка\n")
```

Режим `"a"` дописывает в конец файла; если файла нет, он будет создан. `write` не добавляет перевод строки сам — его пишут в конце строки явно.

Режим `"w"` стирает файл и пишет заново — для результатов экзамена он не подходит.

## Строки с подстановкой

```python
name = "Аня"
level = 3
print("%s;%d" % (name, level))
print(f"{name};{level}")
```

Обе строки печатают `Аня;3`. `%s` подставляет строку, `%d` — целое число. В f-строке значения подставляются в фигурных скобках.

## Флаг запуска

Что написано после имени программы, лежит в списке `sys.argv`:

```python
import sys

if "--stable" in sys.argv:
    print("устойчивый итог")
```

Запуск `python3 src/exam.py --stable` выполнит строки под этим `if`, а без флага — нет. В `main()` в `exam.py` такая проверка для `--stable` уже есть; проверку своего флага добавляют так же.

## Shell-скрипт запуска

`run_exam.sh` — обычный shell-скрипт из первого дня. Он запускается из корня репозитория и содержит команду запуска экзамена. Чтобы флаги, написанные после `bash run_exam.sh`, дошли до программы, в конце команды пишут `"$@"`:

```bash
python3 src/exam.py "$@"
```
