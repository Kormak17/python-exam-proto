## Запуск и переменные

Программа на Python — текстовый файл с расширением `.py`. Запуск: `python3 путь/к/файлу.py`.

Код выполняется сверху вниз. Переменная хранит значение; знак `=` записывает значение в переменную:

```python
city = "Казань"
year = 2026
print(city)
```

Текст пишут в кавычках: `"кот"` — строка, а `кот` без кавычек Python считает именем переменной. Комментарий начинается с `#` и не выполняется.

## Вывод

| Операция | Действие |
| --- | --- |
| `print("текст")` | Напечатать текст и перейти на новую строку |
| `print(city)` | Напечатать значение переменной |
| `print("а", "б")` | Напечатать через пробел: `а б` |
| `print()` | Напечатать пустую строку |

Каждый `print` заканчивает строку переводом строки. Несколько `print` подряд печатают несколько строк.

## Ввод

```python
line = input()
```

`input()` ждёт, пока человек наберёт строку и нажмёт Enter, и возвращает эту строку без перевода строки. Если ввод закончился совсем (строк больше нет), `input()` останавливает программу с ошибкой `EOFError`.

Другой способ прочитать строку:

```python
import sys

line = sys.stdin.readline()
```

`sys.stdin.readline()` читает одну строку вместе с переводом строки в конце. Если ввод закончился, он возвращает пустую строку `""` и программу **не** останавливает. `import sys` пишут один раз в начале файла.

Пустая строка (человек просто нажал Enter) и конец ввода (строк больше нет) — разные случаи. В первом `readline()` вернёт `"\n"`, во втором — `""`.

## Строки

| Операция | Что делает | Пример |
| --- | --- | --- |
| `text.strip()` | Убрать пробелы и переводы строки по краям | `"  лес \n".strip()` → `"лес"` |
| `text.lower()` | Все буквы сделать маленькими | `"ЛеС".lower()` → `"лес"` |
| `text.upper()` | Все буквы сделать большими | `"лес".upper()` → `"ЛЕС"` |
| `len(text)` | Длина строки | `len("лес")` → `3` |
| `a + b` | Склеить строки | `"ле" + "с"` → `"лес"` |
| `a == b` | Строки совпадают полностью | `"лес" == "Лес"` → `False` |
| `a in b` | Строка `a` встречается внутри `b` | `"ес" in "лес"` → `True` |

Методы можно применять один за другим: `text.strip().lower()` сначала убирает пробелы по краям, потом делает буквы маленькими.

`strip()` убирает пробелы только по краям. Пробелы внутри строки остаются: `" л ес ".strip()` → `"л ес"`.

Сравнение `==` учитывает каждый символ: большие и маленькие буквы, пробелы, скобки. `"лес" == "лес "` → `False`.

## Условия

```python
word = "лес"
if word == "":
    print("пусто")
elif word == "лес" or word == "бор":
    print("деревья")
else:
    print("что-то другое")
```

После `if`, `elif` и `else` стоит двоеточие. Строки, которые выполняются при условии, сдвинуты на четыре пробела. `elif` — следующая проверка, если предыдущие не сработали. `else` — что делать, если не сработала ни одна.

| Операция | Значение |
| --- | --- |
| `==`, `!=` | Равно, не равно |
| `<`, `<=`, `>`, `>=` | Меньше, не больше, больше, не меньше |
| `and` | Оба условия верны |
| `or` | Хотя бы одно условие верно |
| `not` | Условие неверно |

`=` записывает значение, `==` сравнивает. Табуляции и пробелы в отступах не смешивают.

## Числа и цифры

Ввод всегда приходит строкой: `"2" + "3"` даёт `"23"`, а не `5`.

| Операция | Результат |
| --- | --- |
| `int("42")` | Целое число `42` |
| `int("4.2")`, `int("сорок")` | Ошибка `ValueError` |
| `str(42)` | Строка `"42"` |
| `text.isdigit()` | `True`, если непустая строка состоит только из цифр: `"42"` → `True`, `"-4"` → `False`, `""` → `False` |

Прежде чем превращать строку в число, проверь её: `int()` на неподходящей строке останавливает программу.

## Код завершения

Программа, которая дошла до конца без ошибки, сама завершается с кодом `0`. Если программа остановилась из-за ошибки (в терминале появился `Traceback`), код будет другим.

Напечатанный текст на код завершения не влияет: программа может напечатать `нет ответа` и завершиться с кодом `0`. Код смотрят в терминале командой `echo $?` сразу после запуска.

## Для дополнительных заданий: списки

| Операция | Что делает | Пример |
| --- | --- | --- |
| `text.split(",")` | Разделить строку по запятым в список | `"a,b,c".split(",")` → `["a", "b", "c"]` |
| `len(items)` | Сколько элементов в списке | `len(["a", "b"])` → `2` |
| `x in items` | Есть ли элемент в списке | `"a" in ["a", "b"]` → `True` |
| `items.count(x)` | Сколько раз элемент встречается | `["a", "a", "b"].count("a")` → `2` |
| `sorted(items)` | Новый список по порядку | `sorted(["b", "a"])` → `["a", "b"]` |
| `items == other` | Списки совпадают поэлементно | `["a", "b"] == ["a", "b"]` → `True` |

`split(",")` оставляет пустые элементы, если между запятыми ничего нет: `"a,,b".split(",")` → `["a", "", "b"]`. Пробелы вокруг элементов тоже остаются: `"a, b".split(",")` → `["a", " b"]`.

Перебрать элементы списка:

```python
for item in ["лес", "бор"]:
    print(item.upper())
```

## Справка без интернета

Краткая документация доступна прямо в терминале:

```bash
python3 -m pydoc str.strip
python3 -m pydoc str.lower
python3 -m pydoc str.isdigit
```

Выход из справки — клавиша `q`. Сообщения об ошибках разобраны в [справочнике traceback](traceback_40_rus.md).
