# Тесты и линтер

Как во втором дне: тесты проверяют, **правильно ли считает** код, линтер — **аккуратно ли он написан**. Задание засчитано, когда довольны оба.

## Тесты

```
python3 testing/run_tests.py        — все задания
python3 testing/run_tests.py 1      — только Задание 1 (или 2, 3, 4, 6)
python3 testing/run_tests.py всё    — только экзамен целиком
```

Для каждой части тесты пишут одну строку:

| Ответ | Что означает |
| --- | --- |
| `Задание 1 (answers.py): пройдено` | Функции задания работают как надо |
| `… : не начато` | Функции ещё возвращают простейшие ответы заготовки |
| `… : не пройдено — …` | После тире — первая найденная причина: какой вызов, что ожидалось, что получено |
| `Экзамен целиком: ждёт заданий 2, 3` | Сборку проверять рано: не готовы названные задания |
| `Экзамен целиком: пройдено` | `exam.py` запущен как настоящий экзамен на выданном банке и отвечает как надо |

Тесты каждого задания проверяют только свой файл. Поэтому каждый может проверять свою часть, не дожидаясь коллег. Тест Задания 4 смотрит на ваш настоящий `datasets/team.csv`: от 10 до 20 вопросов, все три типа, вместе с `bank.csv` нет пустых клеток.

Строку «Экзамен целиком» тесты проверяют во временной папке, с выданным банком и своим маленьким `team.csv`. Ваш настоящий `team.csv` на неё не влияет.

## Линтер

```
python3 src/partner/lint.py src
```

| Код | Замечание | Что означает |
| --- | --- | --- |
| `L000` | Файл не разбирается | Синтаксическая ошибка |
| `L001` | Строка длиннее 100 символов | Раздели строку |
| `L002` | Табуляция в строке | Отступы — четыре пробела |
| `L010` | Импорт не используется | Подключён модуль, который не нужен |
| `L011` | Переменная заведена и не используется | Значение посчитано и забыто |
| `L020` | Модуль не должен печатать | `print` в `bank.py`, `answers.py` или `ladder.py`. Печатает только `exam.py` |
| `L021` | Нет импорта модуля | `exam.py` не подключает `bank`, `answers` или `ladder` |
