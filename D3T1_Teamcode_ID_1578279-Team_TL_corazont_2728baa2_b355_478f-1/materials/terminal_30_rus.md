## Работа в терминале

| Действие | Как |
| --- | --- |
| Вставить текст | Ctrl+Shift+V, Shift+Insert или правая кнопка мыши |
| Скопировать выделенное | Ctrl+Shift+C или Ctrl+Insert |
| Прервать набранную строку или запущенную программу | Ctrl+C |
| Повторить предыдущую команду | Стрелка вверх |
| Дописать имя файла или папки | Tab |
| Очистить экран | `clear` |

`Ctrl+V` в терминале не вставляет текст. Если в строке появились символы вроде `^[[200~`, нажми Ctrl+C и вставь текст одним из способов из таблицы.

Команду набирают после приглашения, которое обычно заканчивается знаком `$`. Если программа задала вопрос и ждёт ответа, в этой строке вводится ответ, а не следующая команда.

## Пути

| Команда или обозначение | Значение |
| --- | --- |
| `pwd` | Показать текущую рабочую папку |
| `ls` | Показать имена в текущей папке |
| `ls -l` | То же с подробностями: размер, дата |
| `ls -a` | Показать также имена, которые начинаются с точки |
| `cd путь` | Перейти в указанную папку |
| `cd ..` | Перейти на уровень выше |
| `.` | Текущая папка |
| `..` | Родительская папка |

Путь без `/` в начале отсчитывается от текущей папки: `notes/day.txt` — это файл `day.txt` в папке `notes` внутри текущей папки. Путь с `/` в начале отсчитывается от корня файловой системы.

Команда `python3 tools/tool.py` запускает файл из папки `tools`, но рабочая папка при этом не меняется. Все пути внутри программы отсчитываются от папки, из которой её запустили.

## Файлы и папки

| Команда | Назначение |
| --- | --- |
| `mkdir папка` | Создать папку |
| `touch файл` | Создать пустой файл |
| `cp откуда куда` | Копировать |
| `mv откуда куда` | Переместить или переименовать |
| `rm файл` | Удалить файл |

`rm` не отправляет файлы в корзину: удалённое не вернуть. Перед удалением проверь рабочую папку и имя файла.

## Запуск и код завершения

| Команда | Назначение |
| --- | --- |
| `python3 файл.py` | Запустить программу на Python |
| `bash файл.sh` | Выполнить shell-скрипт |
| `echo $?` | Показать код завершения предыдущей команды |
| `history` | Посмотреть ранее введённые команды |

Интерпретатор указывают явно: `python3 файл.py`, `bash файл.sh`. Если набрать только имя файла, оболочка попробует выполнить его сама и выдаст непонятные ошибки вроде `import: command not found`.

**Код завершения** — число, которое программа оставляет после работы. `0` обычно означает «всё в порядке», другое число — ошибку. Код не печатается на экране вместе с ответом программы: его показывает отдельная команда `echo $?`. Выполни её **сразу** после программы: если между ними была другая команда, ты увидишь уже её код.

```bash
python3 tool.py
echo $?
```

Если программа ничего не печатает и мигает курсор, скорее всего, она ждёт ввода. Строку ввода заканчивают клавишей Enter. Сообщить программе, что ввод закончился совсем, можно сочетанием Ctrl+D в начале пустой строки.

## Просмотр данных

| Команда | Назначение |
| --- | --- |
| `cat файл` | Показать файл целиком |
| `head -n 5 файл` | Первые пять строк |
| `tail -n 5 файл` | Последние пять строк |
| `tail -n +2 файл` | Все строки, начиная со второй |
| `wc -l файл` | Сколько в файле строк |
| `cat -A файл` | Показать невидимые символы: конец строки как `$`, табуляцию как `^I` |

Число после `-n` можно менять. У `cat -A` кириллица может выглядеть необычно — это нормально.

## Поиск и подсчёт

| Команда | Назначение |
| --- | --- |
| `grep "текст" файл` | Показать строки, в которых есть текст |
| `grep -n "текст" файл` | То же с номерами строк |
| `grep -c "текст" файл` | Посчитать строки, в которых есть текст |

`grep` ищет текст в любом месте строки. `grep "кот" notes.txt` найдёт и строку `кот`, и строку `который час`. Чтобы найти ровно то, что нужно, добавь к образцу соседние символы, которые всегда стоят рядом с искомым.

## Потоки и перенаправление

У программы есть стандартный ввод (откуда она читает), стандартный вывод (куда печатает) и поток ошибок. Терминал позволяет подключать их к файлам и другим программам.

| Запись | Действие |
| --- | --- |
| `команда < вход.txt` | Взять ввод из файла, а не с клавиатуры |
| `команда > выход.txt` | Записать вывод в файл, заменив старое содержимое |
| `команда >> выход.txt` | Дописать вывод в конец файла |
| `команда < вход.txt > выход.txt` | Взять ввод из одного файла и записать вывод в другой |
| `первая \| вторая` | Передать вывод первой команды на ввод второй (канал) |
| `printf 'текст\n'` | Напечатать текст и перевод строки |

Команды в канале можно соединять: `head -n 3 notes.txt | tail -n 1` берёт первые три строки файла и оставляет последнюю из них, то есть показывает третью строку.

Знак `>` перезаписывает файл без вопросов. Имена с пробелами заключай в кавычки: `cat "мои заметки.txt"`.

**Код канала — это код последней команды в нём.** Чтобы узнать код самой программы, запусти её без канала: сохрани вывод в файл через `>`, сразу посмотри `echo $?`, а потом изучай сохранённый файл.

## Сравнение файлов

| Команда | Назначение |
| --- | --- |
| `diff файл1 файл2` | Показать различия двух файлов |
| `cat -A файл` | Показать невидимые символы |

Если файлы совпадают, `diff` ничего не печатает и завершается с кодом `0`. Если различаются — показывает различающиеся строки и завершается с кодом `1`. Строки, которые есть только в первом файле, помечены `<`, только во втором — `>`.

Лишний пробел или отсутствующий перевод строки глазами не видно, но `diff` их заметит. Чтобы понять, в чём разница, посмотри оба файла через `cat -A`.

## Редактор

`nano файл` открывает файл в консольном редакторе. Если файла нет, он будет создан при сохранении.

| Клавиши | Действие |
| --- | --- |
| Стрелки | Перемещение по тексту |
| Ctrl+O, затем Enter | Сохранить |
| Ctrl+X | Выйти |
| Ctrl+W | Найти текст |
| Ctrl+K | Вырезать строку |
| Ctrl+U | Вставить вырезанную строку |
| Alt+U | Отменить последнее действие |

В подсказках внизу экрана `^` означает Ctrl, `M-` означает Alt. Если случайно открылся редактор `vim`, выйти без сохранения можно так: Esc, затем `:q!`, затем Enter.

## Shell-скрипты

Файл `.sh` — это текст с командами оболочки. При запуске `bash inspect.sh` команды выполняются сверху вниз, как если бы ты набирал их по очереди. Пустые строки допустимы, комментарий начинается с `#`.

Пример содержимого учебного файла `inspect.sh`:

```bash
#!/bin/bash
# Показать рабочую папку и её содержимое
pwd
ls -l
```

Скрипт начинает работу в той папке, из которой его запустили. Он не помнит, что ты делал в терминале до запуска: всё нужное должно быть записано в нём самом.

## Справка без интернета

| Средство | Пример |
| --- | --- |
| Справка встроенных команд Bash | `help cd`, `help printf` |
| Краткая справка программы | `ls --help`, `grep --help` |
| Подробное руководство, если установлено | `man grep`; выход — `q` |
| Версии программ | `python3 --version`, `git --version` |

Если команда отвечает `command not found`, проверь, правильно ли она написана. `No such file or directory` — повод сверить `pwd` и путь к файлу.
